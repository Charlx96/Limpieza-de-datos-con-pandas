# Limpieza-de-datos-con-pandas
aqui realizo la limpieza de datos en base a las ordenes de la imagen.
Este repositorio contiene el desarrollo de un flujo de limpieza, procesamiento de un registro de reclamos en el sector eléctrico, basado en los desafíos planteados en la guía visual del proyecto. NOTA: solo es limpieza

## 🎯 Objetivos del Proyecto
El análisis busca responder de forma automatizada a las siguientes interrogantes del negocio:
1. **Tiempo de atención:** ¿Cuánto tiempo tardó la empresa en atender el reclamo del consumidor?
2. **Eficiencia por oficina:** ¿A cuáles N° de reclamos les atendieron más rápido?
3. **Frecuencia de categorías:** ¿Qué categoría de reclamo es la más común?

## 🛠️ Tecnologías y Librerías Utilizadas
* **Python**
* **Pandas:** Para la carga del set de datos (`REGISTRO_RECLAMOS.xlsx`), manejo de valores nulos, conversión de formatos de fecha/tiempo y filtrado avanzado.
* **Jupyter Notebooks:** Entorno de desarrollo para el análisis iterativo.
